# Simulador de Dominó

Dominó em duplas (você + parceiro × 2 rivais), dobre-seis, com três níveis de dificuldade e feedback ao final da partida sobre suas jogadas.

Site estático: tudo está em `index.html`, sem instalação.

## Publicar no GitHub Pages
1. Crie um repositório novo no GitHub (ex.: `simulador-domino`).
2. Envie `index.html`, `README.md` e `.nojekyll` (botão Add file > Upload files).
3. Em Settings > Pages, escolha a branch `main` e a pasta `/ (root)`.
4. Em poucos minutos o site fica em `https://SEU-USUARIO.github.io/simulador-domino/`.
